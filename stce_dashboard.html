📖 Manual Penggunaan
Panduan lengkap penggunaan Ekosistem Keuangan STCE 2025 untuk Bendahara Controller
ℹ Mulai di sini. Baca manual ini terlebih dahulu sebelum menggunakan sistem. Semua data tersimpan di browser Anda secara otomatis.
🚀 Cara Memulai (5 Langkah)
1

Setup RAB & Anggaran

Masuk ke menu RAB & Anggaran → tambahkan pos-pos anggaran sesuai kebutuhan divisi. Ini menjadi acuan seluruh pengeluaran.

2

Input Donasi Panitia

Masuk ke Donasi Panitia → tandai siapa saja yang sudah lunas. Target minimum 95% dari total panitia.

3

Catat Pemasukan Rutin

Setiap ada dana masuk (sponsor, dana usaha, dll), segera input ke menu Pemasukan. Dashboard akan otomatis update.

4

Catat Pengeluaran + Upload Bukti

Setiap pengeluaran dicatat di Pengeluaran. Arsipkan nota/bukti di menu Arsip Transaksi.

5

Monitor Dashboard Harian

Cek Dashboard setiap hari untuk memantau saldo, progres target, dan peringatan dini keuangan.

📌 Fitur Otomatis & Pintasan
🔵

Kalkulasi Otomatis

Saldo bersih, persentase RAB terpakai, progres donasi — semua terhitung otomatis tanpa perlu kalkulator manual.

🟡

Peringatan Otomatis

Dashboard menampilkan alert merah jika: saldo kritis (<Rp2jt), pengeluaran melebihi RAB, atau donasi panitia di bawah 80%.

🟢

Export Data

Gunakan tombol ⬇ Export Data di pojok kanan atas untuk download rekap keuangan dalam format CSV kapan saja.

⚪

Kode Warna Status

Hijau = Aman/Lunas   Kuning = Perhatian   Merah = Kritis

📋

SPO Keuangan

Lihat menu SPO Keuangan untuk aturan baku: batas waktu reimbursement (7 hari), batas disbursement, dan prosedur darurat.

📊 Panduan Membaca Dashboard
💰 Total Saldo

Pemasukan dikurangi pengeluaran yang sudah terbayar. Ini uang yang ada di tangan sekarang.

📈 Progres Target

Persentase dari target pemasukan minimum Rp31.210.000. Harus ≥100% sebelum Main Event.

📉 Realisasi RAB

Pengeluaran aktual vs anggaran. Merah = over budget. Pantau agar tidak melebihi RAB.

💳 Donasi Panitia

Progres pengumpulan donasi panitia. Target minimum 95% dari total panitia.

🚨 Protokol Darurat Keuangan
!

Saldo Kritis (< Rp 2.000.000)

Segera laporkan ke Ketua Pelaksana. Hentikan pengeluaran non-esensial. Percepat pencarian sponsor.

!

Sponsor Melanggar Kontrak

Komunikasikan berkala untuk solusi. Rujuk SPK. Aktifkan backup plan pencarian sponsor.

!

Dokumen Bukti Hilang

Hubungi pihak terkait untuk konfirmasi ulang. Catat di arsip dengan status "Pending Verifikasi".

🚀 Quick Start (5 Langkah)
1

Import RAB dari Excel

Masuk ke menu RAB & Skenario → klik zona import → upload file Excel RAB yang sudah disusun. Sistem otomatis membaca 3 skenario (Optimis/Realistis/Pesimis).

2

Hubungkan Google Form Responses

Di menu Reimburse & DOPA Form → masukkan ID Spreadsheet Google Form Responses → klik Hubungkan. Klik tombol 🔄 Sync kapan saja untuk update data terbaru.

3

Isi DOPA Panitia

Di menu DOPA Panitia → klik nama untuk toggle lunas/belum. Target 95% lunas sebelum Main Event STCE 2026.

4

Catat Pemasukan & Pengeluaran

Setiap transaksi langsung diinput. Dashboard otomatis update grafik & indikator RAB vs Aktual.

5

Monitor Laporan Keuangan

Menu Laporan Keuangan menampilkan grafik komparasi skenario (Optimis/Realistis/Pesimis) vs Aktual secara real-time.

🔗 Integrasi Google Form
ℹ Google Form DOPA, Reimburse, dan Disbursement terintegrasi otomatis via Google Sheets CSV export.

Ambil dari URL: …/spreadsheets/d/[ID INI]/edit…

Sistem akan mendeteksi otomatis kolom berdasarkan keyword:
Nama → nama pengaju · Jenis → reimburse/disbursement · Jumlah → nominal · Keterangan/Keperluan → deskripsi · Bukti → kode/link bukti
🔑 Cara Akses Google Sheets

1. Buka Google Sheets responses → File → Share → Anyone with the link can view
2. Klik Sync untuk mengambil data terbaru (format CSV publik)
3. Data masuk otomatis ke tabel Reimburse & Disbursement

🚀 Quick Start
1

RAB sudah terisi otomatis

RAB STCE 2026 dari Excel Resty sudah di-preload. Cek di menu RAB & Skenario. Bisa juga re-import file Excel terbaru kapan saja.

2

DOPA sudah terisi nama panitia

Daftar PI + BPH sudah otomatis masuk ke DOPA tracker dengan nominal yang sesuai tier. Klik nama untuk toggle lunas/belum.

3

Hubungkan Google Form

Isi ID Spreadsheet di bawah → klik Simpan → klik 🔄 Sync G-Form kapan saja untuk tarik data terbaru (DOPA, Reimburse, Disbursement).

4

Catat transaksi masuk/keluar

Menu Pemasukan & Pengeluaran — Dashboard auto-update setiap ada input baru.

5

Pantau Laporan Keuangan

Menu Laporan Keuangan — grafik komparasi Aktual vs 3 Skenario (Optimis/Realistis/Pesimis) secara real-time.
